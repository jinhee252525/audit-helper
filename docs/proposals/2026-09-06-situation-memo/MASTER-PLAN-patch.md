## §9 검색앱·기능 — MVP 재정의
- **히어로**: 상황입력 → 유사선례·적용상 차이 → 원문 온디맨드 하이라이트 → 증빙목록 → 결재용 검토메모 (+면책/사전컨설팅)
- **검색구조 결정**: 방식 A (FlexSearch+샤딩). 교육 개별학교 기본 숨김. 대시보드 사전집계. 필요 시 B 승격.
- **앞당김**: F3 원문 위치(온디맨드), F4 법령 **링크·확인필요** 최소
- **제외(초반)**: 당시vs현재 규정 자동비교; 나라장터·재정·민원 풀연동
- **제도개선**: F5/보드는 대시보드 인사이트로 (검색 MVP 비포함)
- **도메인 팩**: 계약(1) → 보조금(2)
- **배포**: GitHub Pages
- **‘와’**: 상황 한 번 → 메모 초안+원문 근거+보호받는 길
