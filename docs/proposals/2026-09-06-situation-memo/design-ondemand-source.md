# 디자인: 원문 온디맨드 대조

## 문제
19만 건 메타는 있으나 원문 전량 미확보. 전량 사전수집은 robots/용량/저작권상 비현실.

## 흐름
1. 상황 검색 → 메타로 후보 N건
2. 상위/선택 건에 대해 `document_url` 또는 `source_url` **요청 시 fetch**
3. 성공 → 본문에서 상황 키워드·필드 겹침 문장 하이라이트 → 배지 `본문 확보`
4. 사람이 인용 확정하거나 자동 대조 규칙 통과 시 `근거 대조 완료`
5. 실패(CORS·차단·빈본문) → `목록만` 유지 + “원문 링크만 가능”

## UI 상태
- 대기 / 가져오는 중… / 확보됨(하이라이트) / 실패(사유 짧게)

## GitHub Pages 제약
브라우저 직접 fetch가 막히는 소스 多.
- PoC: 가능한 공개 HTML만 시도, 실패 graceful
- 운영: **허용 소스만 배치 캐시** 또는 최소 프록시 (별도 결정, data 파이프라인과 분리 설계)

## 절대규칙 정합
근거 없는 사례 생성 금지 ↔ 미확보 원문으로 체크리스트/메모 근거 안 만듦
