# 결정 요약 (제안·채택 반영용)

## 채택
1. **MVP 출구**: 상황입력 → 유사선례 · 같은점/다른점 → 원문 하이라이트 → 증빙목록 · 결재용 검토메모 (+ 면책/사전컨설팅 “보호받는 길”) 한 화면
2. **원문 정책**: 전량 사전수집이 아니라 **온디맨드 확보**. 배지 `목록만` / `본문 확보` / `근거 대조 완료`. 본문 미확보 건으로는 체크리스트·검토메모 근거 생성 금지
3. **시범 분야**: 계약 → 보조금 (도메인 팩). 엔진 공유, 스키마·증빙템플릿·시드만 교체
4. **외부 데이터**: **법령 연결만** 우선 (조문 링크 + 현행 확인필요). 나라장터·재정·민원·권익위 풀연동은 후순위
5. **빼기**: 당시 규정 vs 현재 규정 자동비교 (난이도 대비 초반 ROI 낮음)
6. **제도개선**: 검색 MVP가 아니라 **대시보드 인사이트**로
7. **검색구조**: **방식 A — FlexSearch + 샤딩** (GitHub Pages). 교육 개별학교 필터 기본 숨김. 대시보드 사전집계 JSON. 필요 시 나중에 B(SQLite-wasm)
8. **배포**: GitHub Pages
9. **공개판 vs 기관용** 단계 분리 유지

## ‘와’ 포지셔닝 (한 줄)
업무 상황을 넣으면 1분 안에 **결재용 검토메모 초안 + 원문 근거 하이라이트 + 면책으로 보호받는 길**이 한 화면에 나온다. (검색기기가 아니라 판단 지원)
