# 디자인: 도메인 팩 (계약 → 보조금)

## 개념
검색·메모 엔진은 하나. 분야별로 **입력 스키마 + 증빙 템플릿 + (나중에) 시드 사례 필터**만 갈음.

## 계약 팩 (1단계)
### 입력
기관유형, 업무단계, 행위시점, 금액·재원, 변경/예외 사유, 자유서술

### 증빙 후보 템플릿 (예시 — 일반 제안 vs 사례근거 구분 표시)
- 변경 필요성 검토서
- 산출내역
- 협의·회의 기록
- 관련 내부기준/위임전결 확인
- (사례 본문 확보 시에만) 해당 선례가 언급한 증빙 항목

### 완료 기준 (제안)
원문 확인된 계약 관련 핵심 사례로 실제 업무질문 검증 (건수·시드는 **data 작업 완료·사용자 OK 후**)

## 보조금 팩 (2단계)
동일 UI. 입력·증빙 템플릿만 보조금(교부·정산·목적외사용 등)으로 교체.

## 비간섭
시드 선정·필터 실행은 data/ 파이프라인 안정화 전까지 **문서만**. JSON 시드 파일도 사용자 요청 시 `prototypes/` 아래에만.
