# 디자인 계통·스타일 가이드 (제안)

> 기존 `app/` 코드·토큰을 **확장**하는 방향. 구현 반영 전 합의용. data/pipeline 비간섭.

## 1. 디자인 계통 (Design system family)
**공공·신뢰형 업무 콘솔 (Government Trust Console)**

참고 계열:
- 한국 공공 디지털서비스의 **차분한 행정 UI** (과한 스타트업 그라데이션·다크네온 지양)
- 기존 PoC 토큰 계승: `--page #eef1f6`, `--accent #1c5a94`, Pretendard/Apple SD Gothic
- 정보 밀도는 **중간~높음** (검색기처럼 허전하지 않게, ERP처럼 답답하지 않게)

비계통: 소비자 앱 일러스트 중심, 글래스모피즘, AI 보라 그라데이션 남발.

## 2. 스타일 원칙
1. **신뢰가 최우선** — 출처·처분·품질배지가 장식보다 먼저 보인다.
2. **판단은 사람** — UI 카피가 “위법이다/해도 된다”를 단정하지 않는다. 메모는 **초안·빈칸 판단란**.
3. **한 화면 출구** — 상황 입력의 도착점은 검토메모·증빙이다 (검색 목록이 끝이 아님).
4. **품질 배지로 정직** — `목록만` / `본문 확보` / `근거 대조 완료`를 색·라벨로 구분. 미확보 건은 근거 인용 UI 비활성.
5. **면책은 안전판** — 지적 카드와 시각적으로 분리(좌측 포인트 그린), “보호받는 길” 패널.
6. **접근성** — 색만으로 의미 전달 금지(배지 텍스트 병기), 포커스 링, 본문 대비 충분.

## 3. 톤·카피
- 존댓말·짧고 업무적. “AI가 판정했습니다” 금지.
- 권장: “유사 선례”, “적용상 차이”, “확인 필요”, “담당자 판단”
- 금지: “위법 확정”, “처분 예정”, 허위 유사도 과장

## 4. 레이아웃
### AXIS A (실무) — 히어로
좌 상황 폼 30% / 우 선례·비교·하이라이트 / 하 증빙+검토메모 / 우상 또는 사이드 면책 패널

### AXIS B (제도개선) — 대시보드
기존 dashboard 탭 구조 유지·강화 (본 제안의 검색 히어로와 역할 분리)

### 모바일
상단 상황 → 탭 `선례 | 증빙 | 메모`. 폰 지시·현장 확인용.

## 10. 컬러 확정 (2026-09-06 · 녹색 계통 고정)

**채택 방향: Sage / dusty green matte (녹색 계통)**  
파랑·보라 실험은 폐기. 히트맵·기여도 격자 UI 모방 금지. 레이아웃은 **근거 레인 / 거리 비교 / 메모 독**.

| 토큰 | Hex | 용도 |
|------|-----|------|
| page | `#F7F8F7` | 캔버스 |
| surface | `#F0F2F1` | 보조 카드·필드 |
| sage-soft | `#F0F4F1` | 본문 확보 하이라이트 |
| primary | `#5B7C73` | CTA·활성 내비·칩 |
| primary-soft | `#8DA399` | 차트 보조·앰비언트 |
| deep | `#3F5D50` | 리본·강조 라벨·딥 바 |
| tip | `#EBE8DA` | 한 줄 정리 카드 |
| border | `#E0E3E2` | 카드 보더 |
| ink | `#333840` | 본문 |
| muted | `#7A8087` | 보조 텍스트 |

**품질 배지**
- 목록만 → slate/surface
- 본문 확보 → sage-soft + deep 텍스트
- 근거 대조 완료 → deep fill / 밝은 텍스트

**금지**: 태극·국장, 선명한 sky `#0ea5e9`, 블루바이올렛 `#5B6B99`, 유료 디자인 생성.
