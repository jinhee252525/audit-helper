# 감사 선례 도우미 — PRD (요약본)

> 전체 시각 기획서(HTML)와 짝이 되는 저장소용 요약. 상세·근거는 HTML PRD 참조.

## 1. 한 줄 정의
감사원·국회 결산·중앙부처 자체감사·지자체 종합감사의 지적사례와 적극행정 면책·사전컨설팅 사례를 모아,
담당자가 업무 순간(AXIS A)과 제도개선 발굴 순간(AXIS B)에 선례를 결재 전에 확인하게 하는 도구.

## 2. 목표 / 비목표
- 목표: 상황→유사 지적/면책 제시, 사전점검 체크리스트, 반복지적→제도개선 후보, 출처·근거 현행성 표시.
- 비목표: 위법 자동 판정, 담당자 평가, 실시간 감사 대응, 비공개문서 반입, 법령 해석 대체.

## 3. 사용자
실무 담당자(AXIS A) · 제도개선/감사 담당(AXIS B) · 결재권자(요약).

## 4. 기능(우선순위)
- F1 상황 기반 유사 지적 검색(RAG) — P0
- F2 업무유형별 사전 점검 체크리스트 — P0
- F3 기안문 붙여넣기 위험 하이라이트 — P1
- F4 근거 조문 뷰어 + 현행성 검증(법제처 API) — P1
- F5 반복지적 패턴 → 제도개선 발굴 보드 — P1
- F6 결재권자 요약 카드 — P2
- F7 사례 제보·피드백 — P2
- F8 적극행정 안전판(지적↔면책 대조 + 사전컨설팅) — P1
- F9 예산·사업 연결(타 지역 편성 비교) — P2
- F10 반복지적 Top · 신규 피드 · 구독 알림 — P1

## 5. 데이터
- 소스: 감사원 / 국회 결산 / 중앙부처 자체감사 / 지자체 종합감사 / ALIO / 적극행정 면책·사전컨설팅.
- 수집: **API 키 없이 Claude가 직접**(정적은 읽기, JS 사이트는 브라우저형).
- 스키마: `schema/finding.schema.json` (지적·면책 통합, disposition null 허용).
- 필터 축: 업무유형·기관유형·연도·법령.

## 6. 지속 축적(Living Knowledge)
- 경로① 자동 일일 수집(Claude 예약 작업, 키 없음) / 경로② Claude로 수동 축적.
- 증분·중복 제거(id), 검수 큐(사람 승인), **지속 저장소 필수**(예: GitHub 커밋 → 사이트 재배포).
- **구현(현 단계·인터넷망):** `scripts/daily_update.sh`(크론) → Claude Code 헤드리스가 `pipeline/daily_prompt.md`로 매일 수집·append·커밋. 상태 `data/state.json`, 로그 `data/runs/`. **내부망 이전은 아주 나중.**

## 7. 아키텍처(2트랙)
- Track 1 PoC: 정적 사이트 + 브라우저 검색(사전계산 임베딩). 공개·시연용.
- Track 2 내부배포: 범정부 공통기반/전용 모델 RAG. 망분리 대응.
- 접착면 = `finding.schema.json`. 외부 키는 법제처(조문)만.

## 8. 지표
Top-k 정확도 · 근거 유효율 · 기안 전 조회율 · 반복지적 추세 · 발굴 과제 수 · 오검출 신고율.

## 9. 리스크
오탐 신뢰 / 지자체 수집 난도 / Claude 직접 수집 한계(JS·약관) / 근거 현행성 / 데이터 라이선스 / 모델 반입.

## 10. 경쟁·재사용 (AI 정부 실험실) — 상세 `docs/reuse-and-landscape.md`
- 직접 중복 과제 없음(감사 지적·면책 통합 검색). 부품은 재사용:
  F4 ← 소방청 `korean-law-markdown`(법제처 XML→마크다운), F9 ← `나라예산 한눈에`(예산 수집·검색),
  계약/여비 ← 조달법령 검색·contract-king·여비업무통합도우미.
- 배포: 행안부·NIA **AI 정부 실험실**(공공 GitLab) 등록 → 인터넷망 검증→보안게이트→업무망 이전.
  우리 Track 1/2가 이 구조와 일치. 지속 저장소는 내부에서 공공 GitLab 커밋으로 대체.
- 외부 유사(충실이·법제처 Lawbot·서울시 LLM)는 범용/법령 축이라 직접 중복 아님.

## 11. MVP(M0)
F1·F2·F8·F10 + 정적 배포. 이후 F3/F4(korean-law-markdown 재사용)/F5/F9(나라예산 한눈에 재사용).
